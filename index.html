Веб-разработчик с 3-летним опытом

Привет! Я Даниил, веб-разработчик с более чем 3-летним опытом, специализируюсь на backend-разработке. Создаю надёжные и масштабируемые веб-приложения, продумывая архитектуру и бизнес-логику.

Хотя моя основная зона ответственности — серверная часть, также имею опыт работы с frontend'ом, в частности с React.js. В моём портфолио есть полнофункциональная ERP система на React 19 и Node.js, REST API для системы вендинга на .NET 8.0, и Telegram Bot для управления ERP системой. Постоянно развиваюсь, изучаю современные технологии и стремлюсь писать чистый, поддерживаемый код.
