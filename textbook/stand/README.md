# Учебный стенд

Локальное приложение для практикума по аудиту веб-приложений. Маршруты слушают только 127.0.0.1. Данных реальных людей нет.

```bash
npm install
npm test
npm start
```

При проверке рукописи тесты проходили на Node.js 22.14.0, установленный Express был версии 4.22.3. PostgreSQL для тестов не нужен.
